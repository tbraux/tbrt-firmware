# AUX-N

Firmwares proposés par AUX-N manager. Un fichier par version, nommé
`aux-n-<version>.hex` (exemple : `aux-n-26.10.64.49.hex`). La page propose
la plus haute ; les autres fichiers de ce dossier sont ignorés.

Le `.hex` est celui que produit la compilation :
`products/aux-n/.pio/build/teensy40/firmware.hex`, renommé.
